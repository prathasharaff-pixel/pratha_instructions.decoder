* An agent that uses that Skill inside a multi-step loop: perceive -> reason -> act -> observe - not a single one-shot prompt
* 1-2 MCP connectors your agent actually calls (web search, filesystem, GitHub, or whatever fits your problem)
* Chain all of it into ONE workflow that runs end-to-end on a real input

This is a required exercise proving you can operate at AI-Involvement. Whether your actual capstone should stay there, or a simpler prompt is the right call, is something you'll defend at the Capstone, for now, prove you can build it.
